The Kronuz C++ library collection

One small library for the part you need.

Familiars is my collection of standalone C++ building blocks. Each has one job and its own repository. Most are header-only; you can take the few you need and leave the rest.

CMakeLists.txt
include(FetchContent)

FetchContent_Declare(hashes
  GIT_REPOSITORY
    https://github.com/Kronuz/hashes.git
  GIT_TAG main)
FetchContent_MakeAvailable(hashes)

target_link_libraries(my_app
  PRIVATE hashes::hashes)

Use one

Drop it into your build.

Each repository has its own README, tests and CMake target named <name>::<name> (dashes become underscores). Link the target and its declared dependencies follow. Most libraries target C++20; the individual README gives the exact requirement.

Where they came from

Built for real systems. Kept for the next one.

The collection began with pieces I pulled out of Xapiand. Others came later, including parts that help build Detent. The Familiars series opens them one by one: the constraint that shaped each library, the mechanism inside it, and the case where I reach for it.
