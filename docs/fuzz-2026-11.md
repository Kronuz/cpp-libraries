## Reproduction

In each target repository:

```sh
quiet check
cmake -S . -B build-fuzz -DBUILD_FUZZING=ON -DCMAKE_CXX_COMPILER=clang++ -DCMAKE_BUILD_TYPE=RelWithDebInfo -DCMAKE_CXX_FLAGS="-O1 -g -fsanitize=fuzzer-no-link,address,undefined -fno-sanitize-recover=all"
quiet light parser-fuzz-build 10 "Build instrumented parser" -- cmake --build build-fuzz --target TARGET_fuzzer -j4
quiet light parser-fuzz-chunk 30 "Fuzz one bounded chunk" -- sh fuzz/run.sh build-fuzz/fuzz/TARGET_fuzzer .scratch/fuzz 1700
```

`TARGET` is `http_parser`, `base_x`, `boolean_parser`, `cuuid`, `datetime`, `strict_stox`, or `radix_router`. On macOS use Homebrew LLVM rather than AppleClang, and the matching libc++ library search path where required. The checked-in per-repository README and actual build-job command include those details. Configure is part of the build hold in the recorded jobs.
